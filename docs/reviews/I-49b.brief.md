## Goal

For an `otherName` verdict of «¿Cómo se dibuja?» (name → drawing) with a non-null `verdict.diagnosis` (built by `src/reverse/diagnose.js`, phase I-49a), the results panel must:

1. put `diagnosis.message` between «…pero se llama «X».» and «Pulsa «Ver paso a paso» para ver por qué.»; a `null` diagnosis and every other verdict kind keep their previous text exactly;
2. highlight the student's chain (`diagnosis.student` atom/bond ids) beside the app's parent chain (`diagnosis.parent`), distinguishable and accessible (not colour alone; legend), in the normal and the 90° view, obeying the highlight switch (`organicWeb.highlights`, «Resaltar en el dibujo»);
3. offer «Ver el paso», opening the stepper at the diagnosis's step computed via `diagnosisExplanation(verdict, explain)` → `{naming, steps, index}` — the explanation of the naming in the student's prefix style — never `explain(verdict.naming)`;
4. not say the old-style message twice (an `OLD_STYLE` diagnosis vs the existing old-style note);
5. be cleared by Deshacer of the load and by any chemical edit, kept by coordinate-only edits (design §15.9 trap 1);
6. work keyboard-only and on a narrow viewport; Ayuda line in «Del nombre al dibujo»; `CLAUDE.md` v4 sentence updated.

## Worker's decisions (judge them)

- **Style:** for a diagnosed verdict the whole stepper (both «Ver paso a paso» and «Ver el paso») shows the student-style explanation; «Se llama» and «Otras formas válidas» keep the app's default name; when the explained name differs, an extra line before the diagnosis names it and says the stepper uses it. Consequence: with the stepper closed, the canvas locants follow the explained (student-style) naming, not the «Se llama» name (e.g. `6-metil-4-(propan-2-il)nonano` → canvas numbered as `4-metil-6-(propan-2-il)nonano` while «Se llama» shows `4-isopropil-6-metilnonano`). Is that coherent, or does it confuse the student?
- **OLD_STYLE:** an `OLD_STYLE` diagnosis replaces the old-style note; beside any other diagnosis the note stays. Added `VERDICT_TEXTS.oldStyle` in `src/reverse/index.js` (note text unchanged).
- Existing e2e/unit assertions for `metiletano` / `2-buteno` and one `verdictBlock` unit test were changed because the text changes by design — check they were not weakened.

## Risks to probe

- Stale state: the diagnosis highlight, legend, «Ver el paso» or student-style stepper surviving Deshacer, a chemical edit, a new «Dibujar», a drawn-molecule result (`showResult()`), «Ordenar dibujo», or the 90° toggle; the stepper opened from a previous verdict.
- The stepper index: `diagnosisExplanation(...).index` used against the same `steps` array it was computed for; off-by-one; null index / missing step.
- The student-style naming leaking into places that must show the default name (the «Se llama» line, alternatives, canvas after the verdict is cleared).
- Highlight rendering: student vs parent identical chains; ids that are not on the canvas; highlight switch off; 90° view projection.
- Accessibility: legend text, focus after «Ver el paso», keyboard reachability; no `alert`/`confirm`/`prompt`.
- Engine purity: `src/naming/` and `src/reverse/` must stay DOM-free and never read coordinates.
- Code rules: JSDoc on every added/changed function; closing-bracket comments on functions/loops over 10 lines; comments in English, UI text Spanish.
