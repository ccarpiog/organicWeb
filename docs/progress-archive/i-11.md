# I-11 — Redraw and examples

Spec: `autoclaude/processed/110-redraw-examples.md`; design `docs/design.md` §7, §9.
Risk class: routine. Worker model: opus (one worker, resumed once for review fixes).

## Acceptance

- Unit test `tests/unit/layout.test.js`: for all 176 fixture molecules the
  canonical layout keeps ids/topology, has no two atoms closer than 0.5 bond
  length, no bond crossings, and parent x strictly increases with locant — met.
- e2e `tests/e2e/redraw.spec.js`: load example, name, Ordenar dibujo, undo
  restores coordinates, name still shown — met (plus click-during-animation
  regression).

## What was built

- `src/layout/canonical.js` `canonicalLayout()`: parent zigzag left→right from
  locant 1, triple/cumulated centres straight, substituent zigzags on free
  sides, local search flipping/rotating subtrees (±60°), then up to four
  wider-angle restarts (±120°); result validated for clearance and crossings.
- Editor: `setCoordinates()` (one undoable coordinate edit) and
  `animateCoordinates()` (400 ms, skipped under `prefers-reduced-motion`,
  recentres if needed). A pointer press during the animation only finishes it.
- UI: "Ordenar dibujo" in the toolbar and in the post-naming hint; name kept;
  parent highlighted, locants from the numbering step on. Ejemplos menu in the
  header (14 molecules, keyboard navigable).

## Decisions

- Ordenar dibujo with no name shown names the molecule first; on an already
  ordered drawing it adds no undo step and says "El dibujo ya está ordenado."
- Steps offering options (Opción A/B, candidate chains) leave the canvas
  without the extra parent highlight.
- Example menu labels describe the feature ("Alcano ramificado"), not the name.
- Examples load already ordered.
- If a layout still fails validation, the drawing is left unchanged with an
  in-page Spanish message.

## Review

Codex, ship-with-fixes (`docs/reviews/I-11.md`):
- BLOCKER click during animation hit-tested final coordinates → fixed
  (press ends animation, edits nothing), e2e regression.
- SHOULD-FIX layouts with crossings returned as success → fixed (validation +
  restarts + UI fallback), unit test asserts no crossings.

## Known limits

- Random molecules: 0 invalid up to 20 C, ~1/800 up to 40 C, ~3/150 at 50–60 C
  (fall back to the message). Worst case ~1 s per redraw at 50–60 C; <10 ms
  up to 20 C.
