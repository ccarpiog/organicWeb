## Acceptance

- `parseSmiles()` reads C, O, N, F, Cl, Br, I and bracket atoms with explicit H (`[OH]`,
  `[NH2]`); the bracket H count must equal the model-derived one (`SMILES_HYDROGEN`), `[H]`
  rejected. Charges, isotopes, stereo, lowercase aromatic, atom classes and other elements get
  distinct error codes; ring digits still `SMILES_RING` — met.
- `writeSmiles()` writes every element; round trips keep element identity; same-formula
  isomers (ethanol vs dimethyl ether) stay distinct — met.
- Oracle: `heavyAtomTree()` replaces `hydrocarbonTree()` and keeps every heavy atom; formula
  from OPSIN's SMILES via shared `hillFormula()` (`src/model/molecule.js`, also used by
  `formula()`); adapter failures a separate category — met.
- No visible UI change; fixtures and snapshots untouched — met.
