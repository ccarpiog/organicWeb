## What was done

- `validate.js` lifts the `polysubstitutedBenzene` refusal for one OH and/or one amine on the
  ring plus branch/halogen/alkoxy prefixes; OH + amine → OH principal, amine as `amino-` /
  `(alquilamino)-` prefix (`4-aminofenol`, `4-(metilamino)fenol`).
- `aromatic.js` / `render.js` / lexicons: principal group takes locant 1 regardless of Kekulé
  drawing; `fenol` omits its 1, the amine writes it (`bencen-1-amina`); Otras formas: `o/m/p-cresol`
  (phenol with one methyl only), `anilina` forms, old o/m/p forms built on `anilina`.
- `explain.js`: numbering step says the principal group takes 1, no double-bond mention, orto/meta/
  para relative to the group; colour key shows the amine's `-1-`.
- Oracle: `generateRingPrincipalBenzenes()` (500 phenols/benzenamines per run).
- Docs: design §3.2, §13.5, §14 (and I-42b marked Done in its phase table), README, CLAUDE.md,
  Ayuda out-of-scope line, oracle README.

## Decisions

- No `N,p-dimetilanilina` alternative when one multiplied prefix spans N and ring (not in use;
  OPSIN does not parse it); `N-etil-p-metilanilina` is offered. Recorded in design §14.4.
- `4-(metilamino)fenol` (N-substituted amino prefix on a phenol) added to scope; oracle checks it.
- Existing tests that used substituted phenols/anilines as refusal examples now use diols/diamines;
  oracle pinned counts in `oracle.test.js` updated (skipped 75, passed 2161).
