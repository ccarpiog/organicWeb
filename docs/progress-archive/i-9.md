# I-9 — Editor extras (archive)

Spec: `autoclaude/processed/090-editor-extras.md`; `docs/design.md` §6.1, §6.3.
Risk: routine. Worker model: opus (one implementation worker, one fresh worker
for the review fixes).

## Delivered

- Cadena tool: DOM-free `chainPoints()` / `chooseChainSide()` in
  `src/editor/geometry.js`, live "N C" counter (counts carbons the chain adds;
  a click with Cadena does nothing).
- Mover: drag atom, bond or selection; marquee on empty space. Dropping a moved
  atom onto another is refused with the usual toast.
- View: pan (space+drag, middle drag, two fingers), zoom (wheel, pinch),
  "Centrar"; pure view arithmetic in `src/editor/render.js`.
- New `src/ui/canvasbar.js`: live "Fórmula: …" and Esqueleto / Con carbonos
  toggle; label text from pure `atomLabelText()`.
- New `src/ui/autosave.js`: `localStorage` in try/catch, restore via
  `validateStructure()`, corrupt data deleted → empty canvas; display mode
  persisted; after restore the view is centred (`editor.centerView()`).
- Keyboard shortcuts via pure `shortcutFor()` (plus Ctrl/Cmd+Y redo).
- `onEdit({reason, kind})` with kind `chemical` or `coordinates` for edits,
  undo, redo and restore.
- Tests: `tests/unit/editor-extras.test.js`, `tests/e2e/editor-extras.spec.js`;
  three old e2e lookups gained `exact: true` (the "Con carbonos" label also
  matched `{name: 'Carbono'}`).

## Acceptance

- e2e: chain drag carbon count; marquee + move emits only a coordinate edit;
  reload restores; formula updates; shortcuts switch tools; corrupt storage →
  empty canvas — met.
- Unit tests for chain generator and label text — met.
- `npm test` 0 (348), `npm run check` 0, `npm run build` 0, `npm run e2e` 0 (19).

## Decisions

- Restore uses only structural validation (a drawing in progress may be in
  loose pieces) and is not an undo step.
- Mouse-clicked toolbar/bar buttons drop focus so Space pans the canvas; Tab
  focus unchanged.
- `docs/design.md` §2, §6.1, §6.3 edited in place to match.

## Review

Codex, ship-with-fixes, 0 blockers, 2 should-fix — `docs/reviews/I-9.md`.
Both fixed, each with a Playwright regression that fails without the fix:

1. Second touch landing on an atom lost implicit capture after re-render →
   every touch now captured on the SVG root before any refresh;
   `handleLostCapture()` cancels gesture state when the root loses capture.
2. Restored drawing could come back off-screen → `initApp()` centres the view
   after a successful restore (no undo step, no chemical edit).
