## Decisions

- The grid layout already treated heteroatoms as ordinary atoms, so the heteroatom gate in
  `projectRightAngles()` (`src/layout/rightangle.js`) was removed; ether/ester O and amine/amide N
  carry their carbon groups on at right angles (`CH₃–O–C(=O)–CH₃`).
- A chain end may continue the chain line into a branch: nitrile N first, then a singly bonded
  heteroatom, then =O; carbon branches only when there is no other room. Methane derivatives use
  all four directions.
- `rightAngleLabel()` (`src/editor/render.js`) writes `HO` / `H₂N` when the bond comes from the
  right.
- The HETEROATOM (not nameable) note now reads "Todavía no sé nombrar esta molécula: se ve el
  dibujo normal." (`src/ui/canvasbar.js`).
- Editing in the 90° view and stepper highlights already worked on projected positions; no editor
  change, covered by the new e2e.
- Five older tests that expected heteroatom molecules to fall back were updated to the new
  behaviour; README limitations line now names rings only.
