## Decisions / deviations

  `RING_SYSTEM` (`several`), out of scope; tests use `etilciclohexano`/`butilciclohexano`.
- Fused ring side length = the shared bond's length, so it stays regular after Mover.
- Equal-size fused rings: the inner line of the shared double bond goes into the first ring
  found (deterministic).
- Ayuda text lives in `index.html`; it mentions that joined rings cannot be named yet.
