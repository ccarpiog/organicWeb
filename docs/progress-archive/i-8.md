## Decisions

- Drag from empty space with a bond tool makes a two-carbon fragment
  (spec silent).
- A lone carbon is labelled "CH₄" so methane is visible.
- Borrar on a bond removes only the bond; both carbons stay. The model does
  not record how an atom was created, so §6.1's "created only as its
  endpoints" cleanup cannot be applied safely; §6.1 of `docs/design.md`
  updated to match.
- A new or moved atom that would coincide with an existing one: a snapped
  drag end joins that atom if the bond is valid, otherwise the best free
  angle is used; straightening rotates the other side if needed; any
  remaining collision is refused ("No hay sitio: ese carbono quedaría encima
  de otro.").
- Keyboard shortcuts other than Esc are left for I-9 as planned.
