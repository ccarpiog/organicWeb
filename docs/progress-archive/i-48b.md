## Decisions / deviations

- «Tu nombre: …» line added to the verdict block (not in the spec): once the dialog closes the
  student's name is otherwise no longer visible.
- The new drawing is centred via `loadMolecule(…, {center: true})` rather than a separate
  `centerView()` call, so the view change is part of the undo step.
- No real name whose canonical layout fails was found in 2 000 random molecules, so the layout
  failure path is unit-tested only; the e2e forces a refused load instead.
- New Spanish wording pending teacher review: «Tu nombre:», the whole Ayuda section «Del nombre
  al dibujo».
