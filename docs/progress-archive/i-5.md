# I-5 — Naming engine III: recursive preferred substituents

Spec: `autoclaude/processed/050-naming-substituents.md`; design §1.1, §4.5, §4.8.
Risk: high. Worker: opus (general-purpose subagent; same agent applied review fixes).

## Delivered
- `src/naming/substituent.js` — substituent chain = path containing the attachment atom;
  selection: longest → most multiple bonds → most double bonds → lowest free-valence locant
  (FV) → ene/yne locants → most substituents → prefix locants → citation order. Recursive
  nesting; attachment atom and bond order carried as data. `commonName` metadata (vinilo,
  alilo, isobutilo, sec-butilo) on the structure, never in the name.
- `src/naming/render.js` — `( [ {` nesting; di/tri for simple prefixes (including
  parenthesised ones such as `di(propan-2-il)`), bis/tris for compound prefixes;
  alphanumerical order on the complete prefix name (inner multipliers count, `tert-`
  ignored, numbers compared numerically).
- `src/naming/numbering.js` — FV rule for substituents; new **N5**: parent candidates still
  giving different names after N4 are decided by the first point of difference of the
  complete name (letters before locants).
- `src/naming/index.js` — `prefixStyle` `'isopropil'` (default) | `'pin'` | `'substituted'`;
  `alternatives` = the other styles, each a full re-run (never text substitution); a style
  that fails or is unsupported is dropped without discarding the requested result.
- `lexicon.es.js`, `structure.js`, `src/model/graph.js` supporting changes.
- Fixtures: 5th `alternatives` column (§4.8); 30+ I-5 rows; all `pending(I-5)` markers
  removed, incl. the regression `4-(2-metilprop-1-en-1-il)non-1-eno`.

## Decisions
- Substituent rule order puts free valence and ene/yne locants before most substituents
  (IUPAC 2013 P-31.1.4 / P-44.4.1 before P-45.2.1), mirroring the I-4 parent correction;
  the spec's listing had "most substituents" first. Codex agreed.
- `di(propan-2-il)`, not `bis(propan-2-il)`: parentheses separating locants do not make a
  prefix compound (P-16.9; cf. 1,3-di(propan-2-yl)benzene). The spec's acceptance wording
  was superseded; design doc updated.
- `propil` (not `propan-1-il`) is the PIN for saturated end-attached chains (P-29.2);
  `tert-butil` retained as preferred prefix (P-29.6). Findings from knowledge of the 2013
  recommendations, not checked online; recorded in fixture justifications and design §4.5.
- `tert-butil` in `substituted` style renders `1,1-dimetiletil`.

## Open
- The `substituted` alternative is omitted when it would need a nested `-iliden` group
  (e.g. `1-metilidenbutil`) until I-6.
- N5 is exercised by a regression molecule and a unit test; never fired in a 20 000-molecule
  random run.
