# I-40b — Ring acids, aldehydes and ring acyl prefixes (split from I-40)

- Risk: high. Worker: opus. I-40 is split into I-40a (done: rings as prefixes of an OH / ketone /
  amine chain), I-40b (this phase: acids, aldehydes, ring acyl prefixes), I-40c (nitriles and amides
  with a ring: `ringNitrile`, `ringAmide`) and I-40d (ring esters: `ringEster`); design §13.4 records
  the four rows.

## Decisions (IUPAC 2013; from memory where marked)

- Ring or chain: a principal –COOH or –CHO whose carbon X is bonded to a ring carbon
  (`principal.js isRingGroupCarbon()`) counts for the ring in `ringOrChain()` and is left out of every
  chain skeleton, so it never competes as a one-carbon chain (`cyclohexanecarboxylic acid`, not
  `cyclohexylmethanoic acid`); then P-44.1.1 and P-44.1.2.2 exactly as in I-40a.
- Ring parent: X is a suffix group of the ring atom (`suffixSites(…, ring = true)`, SuffixLocant
  `carbon` / `carbonBond`, SuffixStructure `outside`); the ring atom is numbered by N0; suffix
  `-carboxílico` / `-carbaldehído` after the full ending (P-65.1.2, P-66.6.1.1), locant omitted only
  as a lone group on a saturated ring (the existing ring omission rule).
- Benzene: `ácido benzoico` and `benzaldehído` are the main names (retained preferred names, from
  memory); `ácido bencenocarboxílico` / `bencenocarbaldehído` are offered as `benzeneSystematic`,
  labelled "forma sistemática … que usan algunos libros; la IUPAC (2013) prefiere el nombre
  tradicional" (I did not claim IUPAC status for them).
- `ácido fenilacético` / `fenilacetaldehído` for the bare ácido 2-feniletanoico / 2-feniletanal,
  labelled "acepta" (status from memory; the main name stays systematic, as `ácido 2-cloroetanoico`).
- `carboxi-` (P-65.1.2): any –COOH that is not a suffix group, its carbon included and never a branch
  chain carbon (like `ciano-`). Consequence beyond rings: acyclic acids on another carbon piece are
  now named (`ácido 3-(carboximetoxi)propanoico`, `ácido 3-(carboximetoxi)-3-oxopropanoico`), the
  former `carboxySubstituent` cases; that code is now only an unreachable safety net.
- `manyAcids` narrowed to more than two –COOH on one carbon piece (ring atoms left out; message
  `-tricarboxílico`, not `carboxi-`, as for `manyAldehydes`); `manyAldehydes` also applies with a ring.
  Any number of groups on the ring is a suffix (`ciclohexano-1,3,5-tricarboxílico`).
- Ring acyl prefixes (P-65.1.7, from memory): `benzoil`; otherwise ring prefixes + ring name with
  its full ending + `-1-` when the ring name cites locants + `carbonil`
  (`(2-metilciclohexano-1-carbonil)`, `(ciclohex-2-eno-1-carbonil)`). Always enclosed except
  `benzoil` (app decision for readability; `di(…)` / `bis(…)` by the usual simple/compound rule).
- C=O between a ring and a chain: X is an ordinary skeleton carbon (design §13.6), in the chain
  whenever the chain rules reach it — `ácido 5-fenil-5-oxopentanoico`, not `ácido
  4-benzoilbutanoico` (P-44.3 longest chain) — and an acyl prefix only when the chain misses it
  (`ácido 2-benzoilbutanoico`).
- A –CHO bonded to a ring parent below an acid is `formil-`; a –CHO at a branch end is `oxo-` in the
  branch (`2-(2-oxoetil)ciclohexano-1-carbaldehído`).

## Explanation

- `OUTSIDE_GROUP_WORDS` (the ring carbon bonded to the group is carbon 1); count step counts X and each
  `carboxi`; group step `ringGroupSentences()`, `carboxySentence()`; `branchAldehydeTotal()` stops a
  branch –CHO being called «una cetona» (also fixes the pre-existing wording of `3-(2-oxoetoxi)propanal`);
  «Anillo o cadena» counts ring-bonded groups (`ringGroupCount()`); ring step (group not in the ring;
  `hidroxi-`/`oxo-` seniority now from the actual principal group, it said «la cetona» always);
  ring numbering, benzene and assemble steps; `ringCarbonylDescription()`.

## Refusals

- Lifted: `ringAcid`, `ringAldehyde`, `ringAcyl` (messages removed). Narrowed: `manyAcids`.
  Unchanged: `ringNitrile`, `ringAmide` (I-40c), `ringEster` (I-40d), `symmetricRing`,
  `acylSubstituent`. No new refusal reason.

## Review fixes (`docs/reviews/I-40b.md`, ship-with-fixes)

- Should-fix: `explain.js acidCompanions()` called every `oxo` on the parent's last carbon «un grupo
  –CHO en el otro extremo (un aldehído)», so `ácido 5-fenil-5-oxopentanoico` (a ring prefix on that
  carbon) was explained as an aldehyde. The aldehyde is now read from the carbon's attachments: the
  last chain carbon with nothing but the `oxo` on it (a ring prefix or any other group there makes it a
  ketone; a ring parent never has one). `acidCompanions()` is the only locant-based test (every group
  step uses it); `branchAldehydeTotal()` already checked the attachments. Regressions in
  `tests/unit/ring-acids.test.js` (phenyl, cyclohexyl, `ácido 2-fenil-2-oxoetanoico`, scrambled atom
  order; `ácido 5-oxopentanoico` and `ácido 4-metil-5-oxopentanoico` as true aldehydes) and a new
  snapshot (`OC(=O)CCCC(=O)C1=CC=CC=C1`).
