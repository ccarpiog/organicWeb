## Decisions

- Alkoxy forms `metoxi`, `etoxi`, `propoxi`, `butoxi`, `isopropoxi` (alternatives
  `propan-2-iloxi` / `1-metiletoxi`), `tert-butoxi`, `(pentiloxi)`.
- Symmetric ethers refused (`symmetricEther`) only when both identical halves carry the
  principal group (IUPAC uses `oxidi-`).
- Nested ethers (`2-metoxietoxi`, `(metoximetil)`) fall out of the recursion and are named.
- A ring is always the parent side, so `ciclohexiloxi` / `fenoxi` never occur.
- Alternatives: functional-class `etil metil éter`, `dietil éter`, `tert-butil metil éter`;
  `anisol` for metoxibenceno.
- Alkoxy prefix beside other locant-less prefixes is parenthesised (`cloro(metoxi)metano`).
- Spanish alphabetical order (`2-metil-2-metoxipropano`).
- Review fix: N5 whole-name comparison now also compares the full written prefix text with
  punctuation (`prefixNameKey()` `text` in `render.js`, `compareNameKeys()` in
  `numbering.js`), so only identical names reach the atom-ID tie-break; choosing between
  differently bracketed names by character order is a project convention (design §4.4 N5).
