## Decisions

- Element tool keeps the internal id `carbon` (existing tests and selectors);
  `setTool('carbon')` resets the element to C.
- With an element picked: click empty → place; click atom of another element → change it;
  click atom of the same element → grow a new atom (old Carbono behaviour); drag gives the
  element only to the new end atom (the start atom on empty space is a carbon).
- Bond tools always draw carbons; C=O / C≡N = draw the bond, then change one end.
- 90° view with heteroatoms falls back to the normal drawing with the note "Hay átomos que
  no son carbono: se ve el dibujo normal."; Ordenar dibujo shows the "aún no sé nombrar"
  message instead of reordering.
- The "carbono" wording in self-bond / duplicate-bond / change-bond / overlap refusals now
  says "átomo".
- Label text/size estimation lives in the DOM-free `src/editor/labels.js` (re-exported by
  `render.js`) so `geometry.js` sizes hit boxes without the DOM.
- Toolbar is two columns on desktop; on phones it wraps to three rows.
