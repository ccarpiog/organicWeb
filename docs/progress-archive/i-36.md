## Decisions (from memory, not checked online)

- `N` ranks lower than any numeric locant (P-14.3.5).
- Groups on N do not count for locant omission (`N-metiletanamina`); when an `N` locant is
  written, carbon locants are too (`1-cloro-N-metilmetanamina`, ChemDraw style).
- `[etil(metil)amino]`: every group after the first parenthesised.
- `anilina` is the 2013 retained preferred name (P-62.2.1.1.1) but offered as an
  alternative, per the v2 rule "systematic name first".
- Groups on N count as prefixes for chain choice and numbering; so `NCC(CN(C)C)CCN` is
  refused (`substitutedPolyamine`) while a close relative is named.
