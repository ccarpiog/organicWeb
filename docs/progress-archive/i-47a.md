## Decisions (worker, accepted)

- A branch is enclosed in parentheses whenever it shows a locant — equal to `needsEnclosure()` on
  every engine-written name, and avoids `propan-1-il` running into the next word.
- Legacy count mismatch (`1 3 but eno`) → `LEGACY` (the spec's wording), not `LOCANT_COUNT`.
- New situations: a chain inside a compound branch without `il` → `ROOT_END`; closing a compound
  branch with no chain of its own → `TILE_ORDER` on the closing tile; two numbers before `il` →
  `LOCANT_COUNT` (new draft message).
- Tokenizer reads the `an` of `propan-2-il` as the `ano` tile (omitting it gives the same text).

## Deviations / deferred

- `cloro(metoxi)metano` bracket case needs alkoxy/ring tiles → R-4/R-5b.
- Suffix half of rule 4 (`tetrol`, `butano-1,4-diol`) → R-5a.
- All new Spanish error messages are drafts pending teacher review (design §15.6).
- `parse()`/`assemble()` recurse on nesting depth: safe to 2000 nested branches, stack overflow
  near 3000 (`assemble`) / 5000 (`parse`) — unreachable by hand; R-2a's dialog should cap the
  tile count anyway.
