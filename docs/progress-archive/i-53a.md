## What was built

- **readBack(name, expected)** — the round trip of one name: `tokenize()` (no tiles → `noTiles`), `assemble(parse(ids).tree)`
  must give the text back (`assembly`), `readName()` must give `correct` for the engine's first name and `alternative` for any
  other form (`kind:<kind>`), the verdict's text the name and its first name the engine's (`first`), an alternative matched to
  itself (`matched`), `draw` true and the built molecule's aromatic key the generated molecule's (`graph`; either Kekulé drawing
  of a benzene).
- **The tallies** — per source (a generator, `fixtures`, `reach`): molecules (distinct by aromatic key within the source), names,
  names read back, names by form (`first`, the alternative's style, `listed` for a fixture alternative), pinned names, refusals
  (`naming: CODE` for a molecule the forward engine does not name, `readName: <reason>` for an `outOfScope` verdict), failures.
  assertTally() checks: no failure, refusals = `REFUSED[source]` (exact), pins = `PINS[…].met[source]` (exact), every name
  accounted for; the report goes to the test's diagnostics (`ℹ {…}` lines, the counts of the table below).
- **One test per generator** (27, in the oracle header's order), each with its coverage floor (molecules, names) — the counts the
  seeds give; more is fine (a new alternative of the engine's is read too), fewer means a generator or the engine changed.
- **The fixture test** — every row of `names.tsv` (`readFixtures()`): its systematic name `correct`, each listed alternative
  `alternative`, against the row's SMILES graph.
- **REACH** — 8 molecules whose forms the open user questions are about, which the seeds may not draw: the three pinned forms and
  the four forward-engine forms the reverse engine follows (`1,6-bis-tert-butoxihexano`, `ácido
  3,3-bis-(tert-butoxicarbonil)pentanoico`, `butiltert-butilamina`, `propanodioato de etilo y isopropilo`), so they keep reading
  back should the forward engine change them.
- **The pins as tiles** — what a student's tiles for each pinned name read: `tri dec il amina` → `alternative`
  «tridecilamina», N(C₁₀H₂₁)₃; `tridec il amina` → `alternative`, tridecan-1-amina; `di tert-butil éter` → `otherName`
  «di-tert-butil éter», the same molecule; `alcohol bencílico` has no tiles.

## Decisions

- **The names fed are every form the forward engine writes**: `nameMolecule(mol)`'s first name and every alternative — the other
  two prefix styles (`pin`, `substituted`), `traditional` (retained and traditional names: `tolueno`, `acetato`, `anilina`,
  `acetamida`…), `positional` (o/m/p letters), `locants` (`propan-2-ona`), `benzeneSystematic` (`ácido bencenocarboxílico`…),
  `functionalClass` (ether class names) and `amineClass` (amine class names); all nine forms are met. Old-style forms
  (`2-propanol`) are not engine forms: the reverse engine reads them as `otherName` with OLD_STYLE by design
  (`reverse-read.test.js`, `reverse-alcohols.test.js`), so they are not fed. The left-out-locant mutations stay in the family
  files' loops (and were swept here ad hoc, without a filter, below).
- **Stricter than the brief on alternatives:** the brief admits `correct` or `alternative` for a non-first form; the test asks
  `alternative` with `matched.name` the form itself (an alternative is never the first name), and it holds everywhere.
- **Refusals as an exact table, empty.** No generated molecule is refused by either engine: the generators keep only molecules
  that pass validation, and most of them only those `nameMolecule()` names in every prefix style; the reverse engine's refusals
  (two rings bonded together, an `N` beside two amines or amides, `manyAcids`, imides…) concern names the forward engine never
  writes and are tested with students' names in the family files. `REFUSED` is asserted per source, so a future refusal shows with
  its reason instead of being skipped.
- **Pins keyed by the name with an exact count per source** (`met`), not by molecule: one name may be written for two molecules
  (`tridecilamina`), and a seed change shows as a count change.
- **REACH instead of hunting seeds:** no seed so far draws di-tert-butyl ether (the ether family's loop allows its class name but
  never meets it), and `tridecilamina` needs 13 or 30 carbons in one pattern — an explicit list keeps every pin exercised whatever
  the seeds.
- **Sizes:** 1200 molecules per generator in the oracle's default range (4–14 C) — 30 899 molecules, 37 581 names, 41 s
  standalone; larger sizes and counts went to the ad hoc sweep. The cycloalkanes are listed (every ring size 3…30).
- **No fix in `src/reverse/`:** the loop found nothing the reverse engine should read and does not.
