# I-45b — Substituted benzoyl (v3 §14)

- Spec: `autoclaude/processed/220-polysubstituted-benzenes.md` "I-45b"; design §14.
- Risk: high. Worker: opus (one general-purpose worker, resumed once for the review fix).

## Acceptance

- Substituted benzoyl prefixes named wherever plain `benzoil` is named
  (`ácido 2-(4-metilbenzoil)butanoico`, `2-(2-cloro-6-metilbenzoil)…`,
  `3-(4-metilbenzoil)pentano-2,4-diona`, `ácido 2-[(4-clorobenzoil)amino]etanoico`, nitriles,
  amides and aldehydes), invariant under the Kekulé swap and atom-id scrambling — met
  (fixtures, `tests/unit/substituted-benzoyl.test.js`, `tests/e2e/substituted-benzoyl.spec.js`).
- Two rings, any ester in the molecule (I-45c) and a functional group on the benzoyl's ring stay
  refused with accurate messages — met.
- Existing explanation snapshots byte-identical; new ones added — met.
- `npm test`, `check`, `build`, `e2e`, oracle exit 0 — met (see Verification).

## What was done

- `validate.js`: the substituted-benzoyl refusal is removed; the polysubstituted-benzene message
  now says "(fenil, fenoxi o benzoil)".
- `render.js` / `index.js`: the benzoyl ring's own prefixes come before `benzoil`, numbered from
  the carbon bonded to the C=O (Kekulé-neutral, lowest locants, then alphabetical order). The
  whole prefix is enclosed and alphabetised under its first letter. An isopropyl on the ring also
  gives the `propan-2-il` / `1-metiletil` alternatives.
- No retained alternatives (`toluoil`, `anisoil`, o/m/p): the spec's retained-names table lists
  none.
- `explain.js`: describes the benzoyl ring's numbering and prefixes. Fixed an older bug where a
  `benzoil` inside `(…)amino` was described as «formil». Review fix: the enclosure wording
  (parentheses, brackets or braces) now follows the renderer's nesting depth.
- Oracle: new `generateSubstitutedBenzoyls()` (N/8 molecules per run); README updated; oracle test
  counts 81→82 skipped, 2311→2336 passed.
- Docs: design §14, CLAUDE.md scope, README, Ayuda out-of-scope line.

## Decisions (from memory)

- The spec example `ácido 4-(4-metilbenzoil)benzoico` has two rings, so it stays refused as
  `RING_SYSTEM`.
- The ester refusal message ("su benceno lleva otros sustituyentes además del éster") also fires
  when the substituted ring belongs to a benzoyl. It reads loosely; left for I-45c, which lifts
  that refusal.
