# I-15 — 90° condensed-formula view toggle

Spec: `autoclaude/processed/150-right-angles.md`. Risk: high. Worker: opus.

## Acceptance

- Toggle "Ángulos rectos (90°)" in Con carbonos mode, persisted in localStorage
  (`organicWeb.rightAngles`), hidden in Esqueleto with the stored choice kept — met
  (e2e `tests/e2e/right-angles.spec.js`).
- Reference 2,2,4-trimethylpentane drawn as in the user's picture (chain horizontal,
  methyls vertical) — met (unit `tests/unit/rightangle.test.js`).
- Randomized sweep: no label overlaps or crossings in produced layouts; fallback 0/1200
  for 1–14 C, 2/500 for 15–40 C (~2 % at 40–60 C in a manual run) — met.
- design.md §2, §6.1, §6.3, §7 updated — met.
- `npm test` 0 (393), `npm run check` 0, `npm run build` 0, `npm run e2e` 0 (99, source +
  dist) — met.

## Decisions

- **Display-only projection**: pure, DOM-free `src/layout/rightangle.js` computes grid
  positions from the naming engine's parent chain; model coordinates never change, so
  undo/autosave are unaffected and toggling off restores the drawing exactly.
- **Read-only only while the 90° drawing is shown**: tools, the I-14 single-bond chain
  drag, tool shortcuts and Ordenar dibujo are disabled with the note "Desactiva los
  ángulos rectos para editar."; a drag pans; Deshacer/Rehacer/Limpiar/Ejemplos work and
  the view follows the molecule they leave.
- **Fallback** (empty canvas, loose pieces, unnameable structure, placement failed):
  normal drawing, fully editable, toggle still on, short Spanish note (empty canvas: "Los
  ángulos rectos aparecerán cuando dibujes una molécula."). An edit that makes the
  molecule projectable switches to the 90° view automatically. This replaced the
  worker's first version (read-only even in fallback), which left a student reloading
  with the toggle on unable to draw.
- Single branches hang downward (as in the reference picture); no up/down alternation.
- Label widths are estimated, not measured; e2e checks real rendered labels for overlap.

## Review

Codex, ship-with-fixes, 0 blockers — `docs/reviews/I-15.md`. Should-fix: `refresh()`
rendered `core.peekMolecule()` instead of the view state's molecule, so Mover drags
showed no live preview outside the 90° view. Fixed in `src/editor/editor.js` `refresh()`
(draws `state.mol` unless projected or animating); regression e2e "a Mover drag shows
the atom at its new place before the release" in `tests/e2e/redraw.spec.js`, confirmed
to fail without the fix.

## Open risks

- Fully substituted carbons inside sideways branches cannot be placed at 90° → fallback
  (only very crowded molecules).
- On an empty canvas with the toggle on, the first chain drag already switches the view
  to 90° and read-only; further drawing needs the toggle off.
