# Phase I-1 — Project scaffold (archive)

- Spec: `autoclaude/processed/010-scaffold.md`; design.md §1, §2, §10.
- Risk: routine. Worker: opus (one worker, resumed once for review fixes).

## Acceptance
- `npm test` (30 pass), `npm run check`, `npm run build`, `npm run e2e`
  (3 pass, including `dist/index.html` over `file://`) all exit 0 — met.

## Decisions
- `serve` is a zero-dependency Node server (`scripts/serve.mjs`, port 8000)
  instead of `python3 -m http.server`; Playwright serves on 4173.
- `test` script uses `"tests/unit/**/*.test.js"`. design.md §2 and CLAUDE.md
  updated to match.
- `check` = `node --check` over all JS plus a ban on alert/confirm/prompt.
- `scripts/build.mjs` is a hand-rolled bundler (ES modules → one classic
  script). Limits: imports/exports must start a line and use relative paths;
  no circular imports, `import()`, `import.meta`, destructuring or
  multi-declarator exports; imported bindings are copied, not live (never
  reassign an exported `let`).

## Review
- Codex, `docs/reviews/I-1.md`: ship-with-fixes, 0 blockers, 3 should-fix,
  all fixed: multi-declarator exports now rejected; explicit exports beat
  `export *`; a lexical mask (`maskSource()`) keeps comments/strings/templates/
  regex literals out of module-syntax matching. Regression tests added.

## Residual risks
- Regex-literal detection is heuristic (`/` after `)`/`]` is division).
- Duplicate names from two `export *` sources: first wins (ESM drops them).
