## Decisions

- Halogens are simple prefixes, never a suffix, never in the chain; they count as
  substituents for chain choice and numbering after multiple bonds; remaining ties go to the
  first-cited prefix (`2-bromo-1-cloropropano`, `1-bromo-2-metilpropano`).
- Alphabetical order uses the Spanish words (`2-metil-4-yodopentano`); design §1.1.
- Locant omission (from memory of P-14.3.4): one-carbon parent; two-carbon parent with one
  substituent (changed a hypothetical test from `1-feniletano` to `feniletano`); parent fully
  substituted by one kind of halogen (`hexacloroetano`, `hexaclorobuta-1,3-dieno`); ethene and
  ethyne never show their bond locant.
- Halogenated branches are compound prefixes: `(clorometil)`, `bis(clorometil)`,
  `(bromoclorometil)`.
- No traditional names (cloroformo…); the design does not ask for them.
- Refusal message now "…solo nombro hidrocarburos y derivados halogenados…"; Ayuda updated.
- The 90° view still falls back for any non-carbon atom (I-41); Ordenar dibujo works.
- Oracle generator emits halogen derivatives (500 per 1000-molecule run).
