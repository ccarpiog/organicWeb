## Decisions (worker, accepted)

- Left-out slots: a single-value domain (`eteno`, `etenil`) is filled directly; any other gives
  the `incomplete` stand-in («Faltan números: escribe en qué carbono va cada grupo.») until R-1c.
- `metiletano` has a two-value left-out slot → `incomplete` now (§15.5.3 lists it as
  `otherName`, which needs R-1c's search); `1-metiletano` → `otherName` propane is tested instead.
- No real `outOfScope` open-chain hydrocarbon exists within the caps, so `readName` takes an
  optional injected namer for that test and the traditional-alternative hook.
- Old style: `2-buteno` → `otherName` («se llama «but-2-eno»») plus the note; the note rewrites
  the student's own name in modern form (`3-buteno` → «but-3-eno»), the verdict names but-1-eno.
- New draft wordings (teacher review): «La rama…» variants of range/valence messages; 1-carbon
  chain forms (`met eno` → `BOND_RANGE`); a bond locant past the chain end → `LOCANT_RANGE`;
  `SAME_BOND` marks from the first slot to the second; `VALENCE` marks the tile whose bond takes
  the carbon past 4.
- A retained word given its own branches inside a compound branch (`3-(2-metilisopropil)hexano`)
  → `TILE_ORDER`.
