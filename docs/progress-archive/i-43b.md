## What was done

- `validate.js`: the benzene gate is one rule, `ringSinglePrincipal()` — the most senior ring
  group (IUPAC 2013 seniority) must occur exactly once; lower groups become prefixes
  (`hidroxi`, `amino`, `formil`, `ciano`, `carbamoil`).
- `aromatic.js` / `render.js`: retained names never write the group's 1, systematic forms do;
  o/m/p alias only when exactly two ring positions are occupied (`ácido p-metilbenzoico`).
- `explain.js`: benzene/assemble steps and colour key updated; legend bug fixed (showed
  `fen | -ol` for benzoic acid, benzaldehyde, benzonitrile, N-methylbenzamide, benzoates —
  now `benz` + ending; five existing snapshots changed). Ring `ciano-` sentence now says
  «no se cuenta en el anillo».
- Oracle: `generateRingOutsideBenzenes()`; pinned counts in `oracle.test.js` 77 skipped / 2211 passed.
- Docs: design §14, README, CLAUDE.md scope, Ayuda line, oracle README.

## Decisions

- The generalised gate also admits phenols with several amino prefixes (`2,4-diaminofenol`),
  refused in I-43a; oracle confirms them.
- No traditional aliases (`ácido p-toluico`, salicílico, anisaldehído): not in the spec's
  retained-name table.
- A ketone on the ring (`ácido 4-acetilbenzoico`) stays refused for now.
