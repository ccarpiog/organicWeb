## Decisions

- **Split I-54 → I-54a / I-54b** (forward / reader) — the item allows it; the closed loop couples them, handled by asserted pins.
- **The oracle now exits 1 on every seed.** OPSIN 2.9.0 reads a halogen or alkoxy prefix before an unbracketed chain prefix as
  one substituted group (`p-chloromethylbenzene` → `(chloromethyl)benzene`, `p-(ethoxy)methylbenzene` →
  `(ethoxymethyl)benzene`). The user chose `p-clorometilbenceno` knowing this ambiguity (the explanation names it), and the item
  forbids loosening the check, so these stay failures, labelled «known» (`isKnownDisagreement()`). Measured: seed 1 ×1000 16/16
  known, seed 7 ×1000 13/13, seed 42 ×200 5/5, benzene generator ×2000 39 among 453 letter forms. Asked as **Q16** (keep,
  bracket the second prefix — `p-cloro(metil)benceno` reads right in OPSIN —, or drop those cases).
- Per-style letter forms only for two different prefixes; identical prefixes (`o-diisopropilbenceno`) keep one form, as before.
