## Decisions
- `INVALID` message: "Los datos de la molécula están dañados. Empieza un
  dibujo nuevo." (design §3.2 table updated).
- SMILES error messages are English (developer-only input); parser also
  accepts explicit `-`, rejects dots and stereo marks (design §3.1 updated).
- Well-formed JSON with an over-valent carbon restores and reports `VALENCE`.
- Mutators throw on broken references/self-bonds/duplicates/bad orders but do
  not check valence (validate() reports it, per §3.2).
- Atom/bond ids are integers 1..1e9; counters ≤ 1e9+1, always above every id.
- `canonicalTreeKey` roots at the centre atom, or the central bond when
  bicentred; never reads coordinates.
- `tests/unit/model-bundle.test.js` bundles the model with the project
  bundler because `index.html` does not import it yet.
