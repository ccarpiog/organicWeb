## Decisions (from memory — I-7's OPSIN oracle should confirm)
- `isopropiliden` accepted in general nomenclature (P-29.6).
- `eteniliden` for =C=CH₂, no locants, no parentheses.
- Longest chain first inside substituents → `2-metilidenpentil`, not a propenyl name.
- Citation order `metil` before `metiliden`, `etenil` before `etiliden`.
- `propiliden` short form for an end-attached saturated group.
- `di(butan-2-iliden)` (not `bis`), `diisopropiliden`.
- Nested: `6-(3-etilidenhept-1-en-4-il)undecano`; substituted style
  `6-(2-etenil-1-propilbut-2-en-1-il)undecano`.
