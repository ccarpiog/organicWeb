## What was built

- **A track of its own, as the ether's** (`diagnose()` → `classNameDiagnosis()` → `amineClassDraft()`), compared with the
  verdict's naming, which lists the engine's class name (style `amineClass`). In order:
  1. **CARBONYL_SENIORITY** when the engine's principal group is another (`amineClassSeniority()`): the class word names the
     amine as the principal group, as a student's `amina` does, so the same message, built with amineJunior() from the class
     name's nitrogen and its bond to a carbon of the engine's parent (`(2-hidroxietil)amina` → «2-aminoetan-1-ol»,
     `(2-hidroxietil)metilamina` → «…con el prefijo «metilamino»…», `(1-oxoetil)amina` → «etanamida», the amide's own
     nitrogen); step `group`; tiles the class word.
  2. **CLASS_NAME_NONE** (`amine`) when the engine gives no class name: the condition (`simpleAmineGroups`) and the engine's
     substitutive name, with its retained name when it lists one (`anilina`, `N-metilanilina`, `bencilamina`); tiles the class
     word; no focus.
  3. **CLASS_GROUP_WORDS** (`amine`) when the student's group words, rebuilt as the engine writes a class name
     (`amineClassNameOf()`), are not the engine's name; tiles and focus the groups whose word is not the engine's for its atoms
     (`amineClassWord()`, nameSubstituent() read as etherSideName() reads a group).
  4. **CLASS_DI** (`amine`) for a group written twice or with `bis` / `tris` (`compound`); tiles and focus the repeated groups.
  5. **CLASS_ORDER** (`amine`) for the first pair out of the class order (compareClassWords()), with the `tert-` or the
     multipliers' hint when the student's order is right counting them; tiles and focus that pair.
- **The right form quoted is the engine's own class name** (the assembler writes every one exactly, `di-tert-butilamina` too).
- **The class-name step** `amineClass` («Monta el nombre tradicional de la amina», `amineClassStep()`), inserted by
  diagnosisSteps() right after «Reconoce el grupo funcional»: how the name is formed and how it differs from the substitutive
  name, the groups (`amineClassGroups()`: «aquí, «etil» y dos «metil»») and the name; for CLASS_NAME_NONE, the class name in
  general, which amines get one and the substitutive name of this one. Marks: each group on the nitrogen as `substituent`, the
  nitrogen with its bonds as `candidate` (classNameHighlight(), now for an amine's nitrogen too).
- **POSITIONAL** `nitrogen` on `anilina`: «…escribe «N» para el del nitrógeno y un número para el del anillo…».

## Decisions

- **Codes: the ether's class-name codes, no new code.** CLASS_NAME_NONE, CLASS_GROUP_WORDS, CLASS_ORDER and CLASS_DI mean the
  same mistakes for an amine's class name; each takes an `amine` variant of its message (the `oBound` pattern of I-52a3b), the
  ether's text unchanged. Their rule numbers (2, 2, 5, 6) and DIAGNOSES examples stay the ether's; the amine draft gives its
  own step (Diagnosis `step` from the draft).
- **A diagnosis-only step of its own** (`AMINE_CLASS_STEP`), because CLASS_NAME_STEP speaks of the oxygen, the spaces and the
  `-oxi` prefix; inserted after «Reconoce el grupo funcional», the step that introduces the amine; fallback `group`. Its title
  follows the engine's label of the form («nombre tradicional (los grupos unidos al nitrógeno y la palabra «amina»)»): «Monta el
  nombre tradicional de la amina». No explain() change: «Monta el nombre» already lists the class name under «También es
  correcto».
- **A class name beside a senior group is CARBONYL_SENIORITY**, not CLASS_NAME_NONE: CLASS_NAME_NONE's «se nombra con la
  terminación «-amina»» would be false, and the student's mistake is the same as a junior `amina` suffix's (R-6c4a); this also
  covers an amide (`(1-oxoetil)amina`), as R-6c4a's `N-acetiletanamina` — no R-6d null is added.
- **The messages quote the engine's class name, not a form assembled from the student's tree** (the ether's CLASS_DI assembles
  one, for `di-tert-butil éter` against the engine's `ditert-butil`; for amines the engine's form is the assembler's, and a
  half-fixed three-group name, `dimetiletilamina`, would be a wrong name to quote).
- **The retained name in CLASS_NAME_NONE** («(también vale «anilina»)»): beyond the brief («points to the substitutive name»);
  a student writing `fenilamina` most likely means aniline, and the engine lists it.
- **Wording: «En un nombre como «metilamina»…»**, the parser's own phrase for a class name (I-52c3 TILE_ORDER hints), the
  nitrogen named where the ether's message names the oxygen.
- **POSITIONAL** reworded without «localizadores»: the glossary defines «localizador» as a number on a carbon, so «escribe «N»
  para el del nitrógeno y un número para el del anillo» keeps the meaning without calling `N` either.
- **Chemistry:** nothing from memory; every name, form and order is the forward engine's.

## New Spanish drafts (pending teacher review)

- CLASS_NAME_NONE (`amine`): «Un nombre como «etilmetilamina» (los grupos unidos al nitrógeno y la palabra «amina», todo junto)
  solo lo doy cuando el nitrógeno lleva grupos sencillos: cadenas sin ramas unidas por su extremo (metil, etil, propil…),
  isopropil o tert-butil, sin enlaces dobles ni triples, sin anillos y sin más átomos que esos carbonos y el nitrógeno. Esta
  molécula se nombra con la terminación «-amina»: «ciclohexanamina».» — with a retained name: «…: «bencenamina» (también vale
  «anilina»).»
- CLASS_GROUP_WORDS (`amine`): «En un nombre como «metilamina», cada grupo unido al nitrógeno se nombra con su forma más
  sencilla, sin números: metil, etil, propil…, isopropil o tert-butil. Se escribe «isopropilamina».»
- CLASS_ORDER (`amine`): «En un nombre como «metilamina», los grupos unidos al nitrógeno se escriben por orden alfabético:
  «etil» va antes que «metil» (e antes que m). Se escribe «etilmetilamina».»; with the existing hints ««tert-» no cuenta para el
  orden.» and «Los prefijos di-, tri-… no cuentan para el orden.», and the existing reason «con las mismas letras, va primero el
  grupo sin «tert-»».
- CLASS_DI (`amine`): «En un nombre como «metilamina», los grupos iguales unidos al nitrógeno se escriben una sola vez, con «di»
  o «tri» delante: «dimetilamina», no «metilmetilamina».»; with `bis`: «…con «di» o «tri» delante («bis», «tris»… solo van
  delante de grupos que tienen sus propios sustituyentes): «dimetilamina», no «bismetilamina».»
- CARBONYL_SENIORITY on a class name: R-6c4a's wording, e.g. «…Aquí manda el alcohol (–OH), que se nombra con la terminación
  «-ol», al final del nombre; el grupo amino va delante, con el prefijo «metilamino». Se escribe «2-(metilamino)etan-1-ol».»
- The class-name step, title «Monta el nombre tradicional de la amina»; with a class name: «El nombre que explican los otros
  pasos, «N,N-dimetiletanamina», es el que doy primero, el nombre sustitutivo, con la cadena principal y el sufijo «-amina». Una
  amina sencilla como esta tiene también otro nombre, el nombre tradicional, muy usado en los libros. Se monta de otra manera,
  sin cadena principal y sin números.»; «Los grupos unidos al nitrógeno se nombran como ramas, acabados en «-il», cada uno con su
  forma más sencilla y sin números (metil, etil, propil…, isopropil o tert-butil): aquí, «etil» y dos «metil».» (also «aquí,
  «metil»», «los dos son «metil»», «los tres son «metil»», ««etil», «metil» y «propil»»); «Los grupos se escriben por orden
  alfabético, como los sustituyentes de un nombre: «tert-» no cuenta para el orden («tert-butilmetilamina»), y si las letras
  empatan va primero el grupo sin «tert-».»; «Si hay grupos iguales, se escriben una sola vez, con «di» o «tri» delante, que
  tampoco cuentan para el orden: «dimetilamina», no «metilmetilamina»; «etildimetilamina».»; «Al final va la palabra «amina», y
  todo se escribe junto, en una sola palabra. Para esta molécula: «etildimetilamina».» Without one (CLASS_NAME_NONE): «Una amina
  sencilla tiene también un nombre tradicional, muy usado en los libros: los grupos unidos al nitrógeno y la palabra «amina»,
  todo junto, como «etilmetilamina» (el nombre sustitutivo, el que explican los otros pasos, se monta de otra manera, con el
  sufijo «-amina»).»; «Ese nombre se monta sin cadena principal y sin números: los grupos unidos al nitrógeno se nombran como
  ramas acabadas en «-il», por orden alfabético («tert-», «di» y «tri» no cuentan), una sola vez con «di» o «tri» delante si son
  iguales, y al final va «amina», todo junto: «metilamina», «dimetilamina», «etilmetilamina».»; «Ese nombre solo lo doy cuando el
  nitrógeno lleva grupos sencillos: <the CLASS_NAME_NONE condition>.»; «Esta molécula no es una de esas aminas sencillas, así que
  no tiene ese nombre: se nombra como en los otros pasos, con la terminación «-amina»: «bencenamina» (también vale «anilina»).»
- POSITIONAL (`nitrogen`): ««N» y las letras «o», «m» y «p» no van juntas delante de un mismo grupo: con un grupo en el

## Deviations / open questions

- A class name beside a senior group is CARBONYL_SENIORITY (Decisions), outside the four categories the brief lists; the
  brief's own cases never reach it.
- CLASS_NAME_NONE adds the engine's retained name when it lists one (Decisions).
- The multipliers' hint reuses ALPHABETICAL_ORDER's «Los prefijos di-, tri-… no cuentan para el orden.»; in a class name a
  teacher may prefer «multiplicadores».
- The step's tie example is not quoted: the only tie is `butiltert-butilamina`, the engine's open question of I-52c3 (no hyphen
  between the groups); CLASS_ORDER does quote it for `tert-butilbutilamina`, as the engine writes it.
- `etilamina`-style class names stay unannounced on `correct` (I-52c3 open question, unchanged).
- design.md §15.8's Status column is not updated (the user's uncommitted file).
- No forward-engine bug found; nothing in `src/naming/` or `src/explain/` changed.
