  dibujo de un anillo…"; 90° view keeps the "Hay un anillo…" fallback.
- OPSIN oracle checks one cycloalkane per ring size in its carbon range.

## Decisions

- `NameStructure` gains a parent kind (`chain` / `ring`) and a ring parent
  stores its closure bond, so I-26 extends the same shape.
- `CYCLE` code kept with a `ringReason` field instead of a new error code.
- The closure bond is chosen from atom ids (perception order), not from the
  drawing order; names and texts are identical either way.
