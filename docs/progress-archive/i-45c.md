## What was implemented

- Acid side: a substituted ring carrying the ester carbon is the parent, numbered from that carbon.
- O side: substituted phenyl `de 4-cloro-2-metilfenilo`, numbered from the O-bound carbon, no
  parentheses (separate word).
- Two-ring split: each ring is gated on its own in `validate.js`, so both may carry prefixes.
- Also lifted: substituted phenyl/phenoxy/benzoyl inside an ester's acid part; new alternative
  `2-(4-metilfenil)acetato de etilo` («acepta»).
- Explanation: «Separa las dos partes del éster» describes the O-bound ring's numbering and prefixes;
  5 new snapshots, existing ones byte-identical.
- Oracle: `generateSubstitutedEsters()` (250 per run); halogenated benzene esters no longer filtered
  out of `generateRingEsters()` (oracle unit test now expects 83 skipped / 2361 passed).
- ~16 existing tests updated where their refusal expectations covered what this phase now names.

## Decisions (from memory, recorded in design §14)

- No `toluato`, `anisato`, `tolilo`, `cresilo` forms.
- o/m/p form only for a benzoate with one prefix (`p-metilbenzoato de etilo`), never for the
  O-bound phenyl — consistent with I-45a.
- Junior groups (OH, amine, ketone, second ester…) on an ester's ring and benzene diesters stay
  refused with a reworded message; `mixedDiester`, `symmetricRing`, lactone and `esterPrefix`
  unchanged.
