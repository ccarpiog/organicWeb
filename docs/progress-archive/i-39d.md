# I-39d — Amide prefixes and pair matrix (v2 §3.19, split from I-39c)

- Risk: high. Worker: opus. Reviewer: Codex (`docs/reviews/I-39d.md`), verdict ship, 0 findings.

## Acceptance

- Amide beside an acid or an ester named as a prefix — met: X in the chain → `amino` + `oxo`
  (`ácido 4-(metilamino)-4-oxobutanoico`), X off the chain → `carbamoil-` (`(metilcarbamoil)`,
  `dicarbamoil`, `bis(metilcarbamoil)`), bonded through N → `acilamino-` (`[acetil(metil)amino]`).
- Two amides on different carbon pieces named (`2-(acetilamino)etanamida`) — met.
- Pair matrix of ácido > éster > amida > nitrilo > aldehído > cetona > alcohol > amina: all 28
  pairs tested, with counter-examples for remaining refusals — met
  (`tests/unit/amide-prefixes.test.js`).
- Both lexicons, explanation (whole-amide highlight), oracle `amide-prefix` generator, fixtures,
  snapshots, e2e (`tests/e2e/amide-prefixes.spec.js`) — met.

## Decisions (from memory, recorded in design §13.4 row I-39d and §13.6)

- The X-in-chain rule copies I-39c's ester rule.
- `acilamino-` (`acetilamino`) rather than IUPAC's `acetamido`-type prefix; `acetamido` not offered
  as an alternative (it changes alphabetical order, needing a full re-run of naming).
- Chain rule P4 (most substituents) no longer counts groups on the suffix nitrogen, so
  `2-(acetilamino)etanamida` (CAS `2-(acetylamino)acetamide`); single amines/amides unchanged since
  every candidate chain carries the same N groups.

## Remaining refusals

`manyAmides` (3+ on one chain, `-carboxamida`), `substitutedPolyamide`, `imide`, `ringAmide` (I-40),
`carbonocyanidic`; `amidePrefix` is now only the engine safety net.

## Open points

- OPSIN confirms structures, not preference.
- On chain ties the N letter still ranks below any number; this decides the three-amide case
  `2-(acetilamino)-N-(2-amino-2-oxoetil)etanamida`.
- Explanation option A/B order still follows atom ids (pre-existing); names are id-invariant.
