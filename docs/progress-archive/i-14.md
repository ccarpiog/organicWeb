# I-14 — Single-bond drag grows a chain

Spec: `autoclaude/processed/140-drag-chain-single-bond.md`. Risk: routine. Worker: opus.

## Acceptance

- Dragging with Enlace simple grows a 120° zigzag chain (Cadena geometry and
  cap) with a live carbon counter; release is one undo step; Esc / pointer
  cancel records nothing — met (unit + e2e, source and dist).
- Click and one-bond drags behave as before; the one-bond preview now shows
  "1 C" / "2 C" — met.
- `docs/design.md` §6.1, Ayuda, keyboard help, tooltips and README updated — met.

## Decisions

- **Cadena tool removed** as redundant; its `h` shortcut now selects Enlace
  simple, whose drag draws chains.
- **Release on an atom**: whenever the pointer is over an existing atom, the
  drag is a one-bond drag to it, however long; the chain never joins atoms.
  Dragging back onto the start atom is still a refused self-bond.
- A full start carbon refuses the chain ("Este carbono ya tiene 4 enlaces");
  a chain carbon landing on an existing atom refuses the whole chain.
- **Double/triple** tools keep one bond per drag (only the first bond of a
  chain could carry the order).
- Four existing tests used drags now long enough to become chains; they were
  shortened to one-bond length, following the new §6.1 rule.
