# Plan

Build the app described in `docs/design.md` (Spanish-language organic
chemistry naming tool for ESO students).

The work is split into twelve phases delivered as autoclaude inbox items,
`autoclaude/inbox/010-*.md` … `120-*.md`, to be executed in filename order.
Each item names the `docs/design.md` sections it implements and its
acceptance criteria. This file adds no phases of its own; the plan is
finished when every queued item is done and the inbox is empty.
